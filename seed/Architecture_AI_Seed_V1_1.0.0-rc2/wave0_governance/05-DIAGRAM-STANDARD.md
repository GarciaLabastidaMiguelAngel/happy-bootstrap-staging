# Estándar de diagramas

## Formatos

- Mermaid: secuencias, estados y flujos.
- C4/PlantUML: contexto, contenedores y componentes.
- ArchiMate: capacidades, aplicaciones, tecnología y motivación.
- Imagen renderizada: Word, PowerPoint o Confluence.

Cada diagrama declara ID, propósito, audiencia, fuente editable, render, documentos consumidores, decisiones y fecha de validación.

Estados: PLANNED → SOURCE_DRAFTED → RENDERED → TECHNICALLY_REVIEWED → APPROVED → EMBEDDED → SUPERSEDED.

## Calidad

- Leyenda y alcance visibles.
- Trust boundaries cuando apliquen.
- Flechas con semántica consistente.
- Niveles arquitectónicos claramente separados.
- Texto legible en tamaño carta.
- Fuente editable conservada.
- Correspondencia con la arquitectura descrita.
