# Architecture AI — Oleada 0: Gobierno documental

Este paquete establece el control de documentación, investigación, diagramas, decisiones, prompts y entregas a Devin.

El libro Architecture_AI_Control_Maestro.xlsx será el registro operativo. Estos archivos Markdown definen políticas y plantillas. Git será la fuente canónica cuando el repositorio documental quede habilitado.

Regla principal: ningún documento cambia a DELIVERED_TO_DEVIN sin confirmación explícita del usuario. Preparar, generar o guardar un archivo no equivale a entregarlo.

## Contenido

- 00-CONTROL-POLICY.md: nomenclatura, versiones y estados.
- 01-DOCUMENT-CATALOG.md: catálogo documental inicial.
- 02-SOURCE-INVENTORY.md: inventario inicial de chats y fuentes.
- 03-EXTRACTION-PROTOCOL.md: extracción de evidencia.
- 04-DEVIN-DELIVERY-PROTOCOL.md: prompts y entregas.
- 05-DIAGRAM-STANDARD.md: diagramas editables y validación.
- 06-QUALITY-GATES.md: puertas de calidad.
- templates/: fichas reutilizables.
